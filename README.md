# Computational Thinking: My UNI Learnings

My coursework, lab worksheets and practice code for the **Computational Thinking (CT)** course at **Habib University**, as part of my BS in Computer Science.

## About this repository

This repo keeps all my CT lab work in one place, with one folder per lab worksheet. Each folder contains the Python solutions I wrote for that lab's questions. I update it after every lab, so it also works as a record of how my problem solving improved over the semester.

## How to run the code

1. Make sure Python 3 is installed. Check with:
```bash
   python --version
```
2. Clone the repository:
```bash
   git clone https://github.com/CodeByFouzan/Computational-Thinking-My-UNI-Learnings-.git
```
3. Move into a lab folder and run a solution:
```bash
   cd Computational-Thinking-My-UNI-Learnings-/LW3_ma12901
   python q1.py
```
